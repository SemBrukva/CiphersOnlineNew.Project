# CiphersOnline → Топ-1 в мировой нише шифрования

> Продуктовая дорожная карта роста: SEO, трафик, монетизация и уникальность продукта.
> Документ стратегический, не технический ТЗ. Каждый пункт привязан к реальной архитектуре проекта.

---

## 0. TL;DR

**Где мы сейчас.** У проекта аномально сильный фундамент для своей стадии: ~57 инструментов в 5 категориях, полная локализация на 8 языков (~456 посадочных страниц), почти образцовое техническое SEO (canonical, hreflang + x-default, JSON-LD: `BreadcrumbList` / `WebApplication` / `FAQPage` / `CollectionPage`, `sitemap.xml` + `.xsl`, `llms.txt`, PWA), семантическое ядро из Yandex Webmaster, внутренний REST API на каждый инструмент + OpenAPI, rate limiting, аккаунты/избранное/кабинет, админка с CRUD контента, менеджером редиректов и трекингом индексации, готовые слоты AdSense + РСЯ.

**Узкое место — не техника, а _типы_ контента и продуктовые надстройки.** Сайт состоит почти целиком из transactional tool-страниц. Не хватает: информационного слоя (верх воронки), виральных механик (permalinks, embeds), продуктовой дифференциации (то, чего нет у dCode/CyberChef/cryptii) и потоков монетизации помимо display-рекламы.

**Стратегия к Топ-1** строится на трёх опорах, которых нет одновременно ни у одного конкурента:

1. **Самый широкий и лучше всего локализованный каталог инструментов** (охват спроса на 12+ языках).
2. **Информационный авторитет** — глоссарий + гайды + разборы, которые ранжируются и кормят tool-страницы (E-E-A-T).
3. **Продуктовая уникальность** — «умный» авто-солвер, шаринг/встраивание, API-платформа и обучающий режим, которого нет у утилитарных конкурентов.

Монетизация диверсифицируется: **API (RapidAPI + ключи) → Pro-подписка (freemium) → партнёрки → оптимизированная реклама**.

## 1. Видение и позиционирование

**Одной фразой:** _«Ciphersonline — место №1, где любой человек в мире может зашифровать, расшифровать, распознать и _понять_ любой шифр — на своём языке, бесплатно, с первого клика.»_

Три аудитории и их job-to-be-done:

| Сегмент | JTBD | Что им нужно от продукта |
|---|---|---|
| **Массовый / любители** (квесты, escape-room, geocaching, TikTok-загадки, школьники) | «быстро раскодировать/закодировать записку» | скорость, распознавание «что это за шифр», мобайл, шаринг |
| **Учащиеся / преподаватели** | «понять, как работает шифр, и показать другим» | пошаговая визуализация, история, встраиваемые виджеты |
| **Разработчики / безопасники** | «встроить кодирование/хеширование в свой процесс» | API, batch, CLI, надёжность, docs |

Конкуренты закрывают эти сегменты частично: dCode — широта, но слабый UX и почти только FR/EN; CyberChef — мощь для инженеров, но пугает новичка; cryptii — красивый UX, но узкий набор и заброшен; boxentriq — контент, но узко. **Никто не делает всё три сегмента × многоязычность одновременно.** Это и есть окно.

## 3. Опора A — SEO и охват спроса

### A1. Информационный слой (наибольший недобор трафика) 🔥

Сейчас ловится только transactional-intent. Мимо проходит весь informational-объём: «что такое шифр X», «как расшифровать без ключа», «виды шифров», «шифры для квеста», «X vs Y».

Три новых типа страниц (по аналогии с существующим контент-JSON пайплайном):

1. **Глоссарий терминов** (`/glossary/{term}`): «частотный анализ», «одноразовый блокнот», «полиалфавитный шифр», «ключ», «модульная арифметика». Короткие, плотно перелинкованные, `DefinedTerm` schema.
2. **Гайды / статьи** (`/guides/{slug}` или `/blog/{slug}`): «Как расшифровать шифр Цезаря вручную», «Топ-15 шифров для escape-room», «История Энигмы», «Шифр Виженера: полный разбор». `Article` schema, длинные, ведут в инструменты.
3. **Хабы-сравнения** (`/compare/{a}-vs-{b}` или раздел): «Caesar vs ROT13», «AES vs RSA», «MD5 vs SHA-256». Ловят «vs»-запросы, высокий intent.

**Реализация в существующей архитектуре:**
- Новый роут-паттерн в `routes.php` (до catch-all `/{alias}` — порядок важен) либо отдельный `ArticleController`.
- Переиспользовать `blocks`-структуру контент-JSON (`docs/cipher-content-json.md`) — завести схему `article-content.v1`.
- В админку добавить CRUD статей рядом с ciphers (`admin_routes.php`).
- Внутренняя перелинковка: каждая статья → 3–6 инструментов; каждый инструмент → 1–2 статьи (расширить логику `cipher_related.php` на статьи).
- Хлебные крошки + sitemap уже поддержат новые URL — обновить `SitemapController`.

**KPI:** +40–60% органических сессий за 6 мес. за счёт информационных запросов; рост среднего числа страниц за визит.

### A2. Семантика на все 8 языков + переоптимизация meta 🔥

Контент на de/es/fr/it/pt/tr есть, но это преимущественно перевод, а не таргетинг под локальный спрос. Семантическое ядро собрано только для ru/en.

- Прогнать сбор семантики (Yandex Wordstat для ru-рынков, Google Keyword Planner / DataForSEO / Ahrefs для латиницы) по остальным 6 языкам → `storage/semantic-core/{de,es,fr,it,pt,tr}`.
- Переписать `meta_title` / `meta_description` / первый экран под локальные формулировки (не дословный перевод: напр. FR ищет «déchiffrer», а не кальку с англ.).
- Использовать `content_recommendations` из семантики (уже есть в схеме) как чеклист.

**KPI:** рост CTR и позиций на неанглоязычных рынках; де-факто разблокировка уже написанного контента.

### A3. Новые языки — почти бесплатное клонирование охвата ⭐

Архитектура делает добавление языка дешёвым (перевод JSON + словарь + `APP_LANGUAGES`). Приоритет по объёму спроса и низкой конкуренции:

1. **pt-BR** (отделить от pt-PT — крупнейший рынок Португалоязычных).
2. **id** (Индонезия — огромная аудитория головоломок, низкая конкуренция).
3. **ja**, **ko** (высокий интерес к шифрам/аниме-загадкам).
4. **zh-Hans**, **ar**, **hi**, **pl**, **nl**, **vi**.

Процесс: сначала машинный перевод (Claude API — уже в стеке знаний) → выборочная человеческая вычитка топ-10 инструментов на язык → семантика.

**KPI:** каждый язык = +N посадочных страниц × средний трафик страницы; кратный рост адресуемого рынка.

### A4. Технические SEO-докрутки ▫️

- **Per-tool OG-изображения** (сейчас один `og-image.jpg`): генерировать динамически (PHP GD/Imagick или headless-скрин) → лучше CTR в соцсетях/выдаче. Кэшировать в `public/`.
- **Self-host шрифта Inter** (сейчас render-blocking Google Fonts) → Core Web Vitals / LCP.
- **`HowTo` / `SoftwareApplication` schema** для инструментов с пошаговыми примерами (у вас уже есть `examples`-блоки — можно мапить в `HowTo`).
- **Хлебные крошки на категориях** уже есть; добавить `SearchAction` (sitelinks searchbox) — поиск по инструментам уже есть (`/api/tools/search`).
- **Sitemap: приоритеты и lastmod** по данным индексации из `tools-overview`.

## 4. Опора B — Продукт и охват инструментов

### B1. Недостающие высокочастотные инструменты ⭐

Закрыть запросы, по которым ранжируются конкуренты, но которых нет у вас. Приоритет по спросу/усилию:

**Классика/коды (высокий спрос, низкий effort — клиентские):**
- Book cipher, Tap code, Semaphore, Braille, NATO phonetic alphabet, Leetspeak (1337), T9/phone keypad, Keyboard shift (QWERTY→), ROT47, ROT-N (обобщённый), Scytale, Nihilist, Four-square, Two-square, ADFGVX, Chaocipher.

**Кодировки/dev (высокий dev-трафик):**
- Base32, Base58 (крипто-адреса), Base85/Ascii85, Base45, Quoted-Printable, Punycode, Gzip/Deflate, ROT13-в-Base цепочки, UUID generator, QR-код (ген/чтение), Barcode.

**Хеши/крипто (dev-трафик):**
- RIPEMD-160, Whirlpool, xxHash, Adler-32; **симметрика**: AES (encrypt/decrypt), ChaCha20; **асимметрика/подписи**: RSA (обучающий), ECDSA verify; HOTP/TOTP (2FA-коды), JWT (у вас есть decoder — добавить sign/verify).

**Утилиты-магниты трафика (off-brand, но огромный объём):**
- Password generator, Random string, Diceware passphrase, UUID, Lorem-в-шифр, Text case converter.

> Рекомендация: держать «магниты» в отдельной категории (`/tools` или `/utilities`), чтобы не размывать нишевое позиционирование, но собирать трафик.

**Реализация:** ваш паттерн уже отработан (миграция + `ToolRegistry` + декодер + контент-JSON — см. память `project-cipher-architecture`). Каждый инструмент = тираж по шаблону.

**KPI:** каталог 57 → 100+ инструментов за 2 квартала; каждый новый tool = новая посадочная × 8–12 языков.

### B2. «Умный» авто-солвер — киллер-фича 🔥

Сейчас есть `CipherIdentifier` (распознаёт тип). Следующий шаг — **распознал → сразу расшифровал**. Это то, за чем массовый пользователь и приходит («у меня записка, что это?»).

- Единое поле ввода → определяет вероятные шифры → прогоняет авто-взлом (Caesar/ROT/Vigenère/Substitution через частотный анализ, у вас уже есть `*-brute-force` и `vigenere-cracker`) → показывает ранжированные кандидаты-расшифровки со скором читаемости.
- Позиционировать как флагман: `/solver` или `/decrypt`. Это отдельная сильная посадочная под «cipher solver / decode any cipher».
- Тяжёлые расчёты — через очередь (`QueueManager` уже есть) + rate limit (есть паттерн для `vigenere-cracker`).

**Почему это Топ-1:** ни dCode, ни CyberChef не дают новичку «вставь текст — получи ответ» из коробки. Это уникальное УТП для массового сегмента.

### B3. Обучающий / визуальный режим ⭐

Дифференциация от утилитарных конкурентов для сегмента «учащиеся/преподаватели»:
- Пошаговая анимация преобразования (буква за буквой) — у вас уже есть визуальные кодировки (dancing-men, pigpen) как задел.
- Режим «покажи промежуточные шаги» (например, матрица Playfair, роторы Enigma).
- Интерактивные мини-упражнения / «попробуй сам».

Это усиливает E-E-A-T, время на странице и виральность в образовательной среде.

### B4. UX-конвейер ввода/вывода ▫️
- Автоопределение направления (encode/decode) и авто-пересчёт.
- Загрузка файла / drag-and-drop, копирование результата, «поделиться».
- История последних операций (для залогиненных — задел под Pro).
- Цепочки операций («рецепты», как у CyberChef, но дружелюбнее) — сильный дифференциатор для dev-сегмента.

## 5. Опора C — Трафик и виральность

### C1. Sharable permalink со state 🔥 (высокий impact / низкий effort)
Кодировать вход/ключ/параметры в URL (`?i=...&k=...` или хэш). Даёт:
- Виральность: пользователь делится ссылкой на готовую расшифровку → трафик + естественные беклинки с форумов/Reddit/квест-сообществ.
- Внутренний UX: сохранённые состояния, «поделиться результатом».
- Осторожно с индексацией: `?`-URL уже `Disallow` в `robots.txt` — оставить так, permalinks не должны плодить дубли.

### C2. Встраиваемые виджеты (embed / iframe) ⭐
`/embed/{category}/{tool}` — облегчённый tool-виджет без шапки. Учителя, блогеры, авторы квестов встраивают ваш декодер → **dofollow-беклинки и брендовая экспансия**. У вас уже модульные `_tool_widget.tpl` — технически близко. Добавить «Встроить» с генерацией кода iframe.

### C3. Публичный API как канал привлечения ⭐
Страница `/api` + листинг на RapidAPI тянет разработчиков и ссылки (см. монетизацию D1). Docs уже генерируются (`openapi.json`).

### C4. Контент-дистрибуция и линкбилдинг ▫️
- Ответы/присутствие в сообществах: r/codes, r/puzzles, geocaching, escape-room форумы, Stack Exchange (Puzzling/Crypto).
- Программные PR-поводы: «индекс популярности шифров» на основе вашей аналитики использования (`/api/analytics/use`) — уникальные данные → цитируемость.
- Digital PR вокруг образовательного контента (глоссарий/гайды).

### C5. Retention: включить аккаунты ▫️
`USER_REGISTRATION` сейчас `false`. Включить + ценность: история, сохранённые workspace, избранное (уже есть), синхронизация. PWA уже настроен → «установить приложение». Готовит почву под Pro.

## 6. Опора D — Монетизация (диверсификация)

Порядок — по потенциалу и готовности инфраструктуры.

### D1. Платный API — самый недооценённый актив 🔥
У вас **уже есть** REST API на каждый инструмент, OpenAPI-спека и rate limiting. Не хватает только продуктовой обвязки:
- API-ключи + тарифы (free / pro / business) по объёму запросов.
- Листинг на **RapidAPI** (быстрый канал платящих разработчиков) + собственный биллинг позже.
- Тарифицируемое: encode/decode/hash/identify/solve, batch, приоритет.
- Инфраструктура ключей ложится на существующие middleware (`ApiAuthMiddleware`) + `rate_limit.php` (лимиты уже по маршрутам).

**Почему первым:** максимальная маржа, актив почти построен, новый B2B-поток, не зависит от рекламного RPM.

### D2. Freemium «Pro»-подписка ⭐
Rate limit + аккаунты = естественный gate. Pro-ценность:
- Без рекламы, без лимитов, batch/файлы, история и сохранённые workspace, приоритетный авто-солвер, экспорт, приватность.
- Кабинет и избранное уже есть — надстроить биллинг (Stripe/Paddle через `HttpClient`).

### D3. Контекстные партнёрки ⭐
На history/FAQ/guide-блоках (нативно, конверсит лучше баннеров):
- Книги по криптографии (Amazon Associates), escape-room киты, курсы по кибербезопасности/CTF, менеджеры паролей, VPN (на dev-страницах).
- Lead-gen для образовательных платформ.

### D4. Оптимизация текущей рекламы ▫️
Слоты уже есть (`after_hero`, `after_first_block`, `after_faq`) для AdSense и РСЯ. Докрутка:
- A/B плейсментов и плотности **без ущерба Core Web Vitals** (реклама не должна ронять LCP/CLS — иначе просядет SEO).
- Гео-таргетинг сети: РСЯ на ru-рынках, AdSense на остальных (частично заложено).
- Отключать рекламу для Pro/залогиненных как часть ценности подписки.

**Целевая структура выручки (12–18 мес.):** реклама ≤ 40%, API + Pro ≥ 45%, партнёрки ~15%. Уход от монозависимости от display.

## 7. Дорожная карта по фазам

> Оценки в «спринтах» относительные; последовательность важнее дат. Каждая фаза заканчивается измеримым результатом.

### Фаза 0 — Быстрые победы (1 мес.) ⚡
Максимальный ROI при малом усилии.
- [x] **Permalink со state** (C1) — виральность.
- [ ] **Self-host Inter + аудит Core Web Vitals** (A4) — фундамент под весь SEO-рост.
- [ ] **Семантика + переоптимизация meta для de/es/fr/it/pt/tr** (A2) — разблокировать уже написанный контент.

**Результат фазы:** рост CTR/позиций на 6 языках, виральный канал запущен, CWV в зелёной зоне.

### Фаза 1 — Информационный авторитет + расширение каталога (2–3 мес.) 🔥
- [ ] **Глоссарий** (`/glossary`) — 40–60 терминов × языки (A1).
- [ ] **Гайды/блог** (`/guides`) — 15–25 опорных статей (A1).
- [ ] Перелинковка статьи ↔ инструменты (расширить `cipher_related.php`).

## 8. Что именно делает продукт Топ-1 (сводка дифференциации)

| Фактор | dCode | CyberChef | cryptii | boxentriq | **CiphersOnline (цель)** |
|---|---|---|---|---|---|
| Широта каталога | высокая | высокая (dev) | низкая | средняя | **высокая + магниты** |
| Локализация | FR/EN | EN | EN | EN | **12+ языков** ✅ |
| UX для новичка | слабый | пугающий | хороший | средний | **лучший** |
| Авто-солвер «вставь → ответ» | частично | нет | нет | частично | **флагман** 🚀 |
| Обучающий/визуальный режим | нет | нет | частично | контент | **да** |
| Публичный API-продукт | нет | (локально) | нет | нет | **да** 💰 |
| Embeds/виджеты | нет | нет | нет | нет | **да** |

## 9. KPI и приборная панель

**Северная звезда:** ежемесячные успешные операции с инструментами (уже трекается через `/api/analytics/use`).

Поддерживающие метрики:
- Органический трафик (сессии), число проиндексированных страниц (уже есть `tools-overview` индексация).
- Средняя позиция / CTR по языкам (Search Console + Yandex Webmaster — интеграция есть).
- Core Web Vitals (LCP/CLS/INP) — не должны деградировать при добавлении рекламы.
- Виральность: доля визитов с permalink/embed-рефереров.
- Монетизация: ARPU, конверсия в Pro, MRR API, RPM рекламы.
- Retention: доля вернувшихся, установки PWA (после C5).

## 10. Риски и как их держать под контролем

| Риск | Митигинг |
|---|---|
| Реклама роняет Core Web Vitals → просадка SEO | лимит плотности, lazy-загрузка, мониторинг CWV в CI |
| Машинный перевод новых языков = тонкий контент | вычитка топ-инструментов, `noindex` до доведения качества |
| Тяжёлые расчёты (solver/cracker) кладут воркеры | очередь (`QueueManager`) + rate limit (паттерн уже есть) |
| Дубли от permalink/`?`-URL | `Disallow: /*?` уже в robots — не индексировать состояния |
| Размывание нишевого бренда «магнитами» (генераторы паролей) | отдельная категория `/tools`, отдельная перелинковка |
| Злоупотребление публичным API | ключи + тарифы + лимиты + мониторинг |
| Юридическое: хеши/крипто как «взлом» | дисклеймеры (в семантике уже есть рекомендации «не обещать взлом») |
